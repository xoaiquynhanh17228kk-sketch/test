# 学校结核病防控现状研究与改革方向 · 科研设计总纲

> **一句话定位**：以初中至大学在校学生为对象，用"文献/政策综述 → 现状实证调查 → 卫生经济学评价 → 差距分析与改革共识"的多阶段混合方法，把结核病防治的关注点从"治已病"前移到"治未病"，并以**卫生经济学**和**基本公共卫生服务**为切入点论证改革方向。

- **研究团队**：临床医生（呼吸科）+ 预防医学 + 疾控/卫生行政管理（"三位一体"结构，正好对应中国结核病防控的疾控机构—定点医疗机构—基层医疗卫生机构分工）
- **研究对象**：初中、高中、中职、大学在校学生（学校是结核病聚集性疫情的高发场所）
- **文档版本**：v1.0 ｜ 面向研究团队的主计划（master plan），后续每阶段产出单独成文
- **配套文件**：`01_研究问题卡_research-question-card.md`（研究契约）、`02_文献与政策检索策略.md`、`03_卫生经济学评价方案.md`

## 摘要：先回答您最关心的方法学问题——"先做综述还是先做 meta 分析？"

**结论：先做综述（而且首选 scoping review / 系统综述），meta 分析不是起点，而是一个"条件性子模块"。**

原因有三，这是本设计的方法学地基：

1. **综述是"现状表述"的骨架**。您的第一目标是"现状表述"，本质是**描述性 + 制图性（mapping）**任务——把"目前学校里结核病是怎么管的、管到什么程度、证据有多少、缺口在哪"系统性地铺开。承担这个任务的是 **scoping review（范围综述，PRISMA-ScR 规范）**，不是 meta 分析。

2. **综述是"要不要 / 能不能做 meta"的前置判断**。meta 分析的前提是：存在一个**聚焦、可回答、有多篇同质定量研究可合并效应量**的问题。学校结核病"管理/政策/经济"这个主题证据高度异质（不同国家/地区制度、不同筛查策略、不同结局指标），**大部分内容根本不可合并**。是否存在一个能做 meta 的窄口子问题（例如"学校主动筛查的结核病检出率""IGRA vs TST 的成本效果"），必须**先靠综述才能看清**。

3. **综述揭示 gap，gap 才是您实证研究和改革建议的立论依据**。没有系统综述先划定"已知/未知边界"，后面的现状调查会失去参照系，改革建议会缺少证据锚点。

> **一句话记住**：**综述在前、实证居中、经济学评价压轴、改革共识收口；meta 分析只在综述过程中"发现可合并的窄问题"时，作为局部模块启动。** 详见 [第 3 节路线图] 与 [第 4 节"综述家族"选型]。

## 1. 研究定位与核心问题

### 1.1 问题转向：从治疗到预防的三级预防再定位

| 层级 | 传统临床关注点 | 本研究前移到的关注点 | 对应措施举例 |
|------|----------------|----------------------|--------------|
| 一级预防（病因预防） | 弱 | **重点** | 健康教育、通风环境、卡介苗、减少传染源暴露 |
| 二级预防（三早） | 部分 | **重点** | 入学体检结核筛查、症状监测、密切接触者筛查、潜伏感染（LTBI）筛查与**预防性治疗（TPT）** |
| 三级预防（规范治疗、防复发） | **强**（临床本行） | 保持 | 规范化治疗、休复学管理、耐药管理 |

> **本研究的价值主张**：把资源和管理注意力从三级向一、二级前移，并**用卫生经济学证据证明"前移是划算的"**。

### 1.2 两个切入点（本研究区别于纯临床研究的关键）

- **卫生经济学切入点**：不只问"有没有效"，更问"值不值得、谁买单、预算多大"。核心是回答——学校主动预防（筛查 + TPT + 健康教育）相对于"等发病再治"，是否**物有所值（value for money）**、能为财政/家庭/社会**节省多少**。
- **公共卫生 / 基本公共卫生服务切入点**：中国 14 项国家基本公共卫生服务中已有"**肺结核患者健康管理服务**"，但它管的是**已确诊患者的服药督导（DOT）**，属二/三级层面，**并不覆盖学校场景的主动预防**。学校结核病防控目前主要依托《学校结核病防控工作规范》，由卫健、教育部门协同、疾控执行，**缺乏稳定的制度化筹资与纳入基本公卫的路径**。→ **这条"缝隙"正是本研究的核心 gap 与改革立论点。**

### 1.3 核心研究问题（三段式）

- **RQ1（现状 · 描述性）**：当前我国（及目标地区）初中至大学学生结核病防控在**筛查、发现、管理、筹资、部门协同、能力**六个维度上的现状与短板是什么？
- **RQ2（评价 · 经济学）**：学校结核病主要预防策略（入学筛查方案、密接筛查、LTBI 筛查 + TPT、健康教育）的**成本、效果、成本-效果 / 成本-效用 / 预算影响**如何？哪种组合"物有所值"？
- **RQ3（改革 · 规范性）**：基于现状与经济学证据，如何从**基本公共卫生服务制度、筹资机制、部门协同、管理能力**层面提出可落地的改革方向？

## 2. 理论框架：给"卫生经济学 + 公共卫生"搭骨架

选定框架不是装饰，而是决定您**调查什么变量、访谈什么问题、评价什么结局**。建议主用以下框架的组合：

1. **三级预防框架**（见 1.1）——组织"措施清单"和"前移逻辑"。
2. **结核病关怀连续体 / Care Cascade**（暴露→感染→发病→诊断→治疗→治愈）——定位"学校环节漏在哪"，每一步的流失率就是干预靶点。
3. **WHO 卫生系统六大模块**（服务提供、卫生人力、信息系统、药品/技术、筹资、领导治理）——作为现状调查的**能力评估维度**，直接回应您说的"管理部门专业能力欠佳"。
4. **中国基本公共卫生服务 + 学校卫生体系**——定位"制度缝隙"，是改革建议的落点。
5. **卫生经济学评价方法谱系**（见第 5 节）——COI → CEA/CUA/CBA → BIA + 决策/传播模型。
6. **实施科学框架 RE-AIM / CFIR**（可选）——若改革建议涉及"如何推行落地"，用它评估可及性、采纳、实施、维持。

## 3. 总体研究路线图（先做什么、再做什么）

> 时间为**建议档期**（团队全职当量约 2–3 人时），可并行处按标注并行。

```
Phase 0  团队共识 & 研究契约          [约 1 个月]
  └ 锁定 RQ、选定理论框架、确定目标地区与数据可及性、方案注册
        │
Phase 1  文献综述 + 政策文件梳理       [约 2–3 个月]   ← "综述先做"在这里
  ├ 1a 政策/规范文件系统梳理（国家—省—校三级）
  ├ 1b Scoping review（PRISMA-ScR）：铺开学校结核病防控证据全景 = 现状文献侧骨架
  └ 1c 【条件模块】若出现可合并窄问题 → 系统综述 + meta 分析（PRISMA 2020，PROSPERO 注册）
        │
Phase 2  现状实证调查（混合方法）      [约 3–4 个月，可与 1 部分并行]
  ├ 2a 定量：监测数据回顾性分析（TB 信息系统、聚集性疫情、筛查检出）
  ├ 2b 定量：横断面调查（学校/机构层面管理现状 + 学生 KAP）
  └ 2c 定性：利益相关者访谈 + 管理能力评估（校医、疾控、卫生行政、学生）
        │
Phase 3  卫生经济学评价              [约 3–4 个月，需 Phase 1–2 的参数]
  ├ 3a 疾病经济负担研究（COI）：先把"学校结核病到底花多少钱"算清
  └ 3b CEA/CUA + 预算影响分析（BIA）+ 决策树/Markov/传播动力学模型
        │
Phase 4  差距分析 & 改革方向共识       [约 2 个月]
  ├ 4a 三源证据整合（文献 + 实证 + 经济学）→ 结构化 gap 清单
  └ 4b Delphi 专家共识 → 可落地改革建议（制度/筹资/协同/能力）
        │
Phase 5  产出与转化                  [贯穿全程，末期集中]
  └ 现状描述论文 + 经济学评价论文 + 政策/改革建议论文 + 政策简报（policy brief）
```

**为什么是这个顺序（决策逻辑）**：

- **Phase 1 必须在 Phase 2 之前**：综述划定"已知边界"，才能设计出"补空白"的调查问卷与访谈提纲，避免重复劳动。
- **Phase 3 必须晚于 Phase 1–2**：经济学模型需要现实参数（发病率、筛查检出率、单位成本、依从率），这些来自您的综述和实证调查。**没有本地参数的经济学模型是空中楼阁。**
- **meta 分析（1c）是条件性的**，不是必经步骤；判断准则见第 4 节。
- **Phase 4 收口**：把三类证据拧成"改革建议"，用 Delphi 让多学科团队 + 外部专家背书，增强政策说服力。

## 4. "综述家族"选型：别把 4 种东西混为一谈

这是本研究方法学最容易踩坑的地方，务必让团队统一认识：

| 类型 | 回答的问题 | 何时用 | 报告规范 | 在本研究中的角色 |
|------|-----------|--------|----------|------------------|
| 叙述性综述（narrative review） | 概览、背景 | 快速了解背景 | 无严格规范 | 仅用于立项背景，**不作主要证据基础** |
| **范围综述（scoping review）** | 这个领域**研究到什么程度、有哪些证据类型、gap 在哪** | **描述"现状"、领域制图** | **PRISMA-ScR** | ⭐ **Phase 1 主力**，产出现状文献侧骨架 |
| 系统综述（systematic review） | 一个**聚焦问题**的证据总体如何 | 有明确 PICO 问题 | PRISMA 2020 | 聚焦子问题时启用（如"学校筛查策略效果"） |
| meta 分析（meta-analysis） | 多研究效应量**合并**后是多少 | 有≥若干篇**同质可合并**定量研究 | PRISMA 2020 + 异质性检验 | **条件模块**，嵌在系统综述里 |

**meta 分析启动判断清单（同时满足才做）**：

- [ ] 有一个足够窄、PICO 清晰的定量问题（如"入学结核筛查主动发现率""IGRA vs TST 成本效果比"）
- [ ] 检索到的研究结局指标**可通约**、测量方式相近
- [ ] 研究数量与质量达到合并门槛（一般 ≥ 5–10 篇同类，异质性 I² 可解释）
- [ ] 合并结果能直接服务于 RQ2 / 改革建议

> 若不满足 → 用**系统综述做定性/结构化叙述合成（narrative synthesis）**即可，同样严谨可发表，不必强行 meta。

## 5. 各阶段方法要点

### 5.1 Phase 1 · 文献与政策综述

- **政策梳理（1a）**：系统收集国家—省—校三级文件（如《学校结核病防控工作规范》《中国学校结核病防控指南》、国家基本公共卫生服务规范中的肺结核患者健康管理、地方实施细则），用**框架法（framework analysis）**按"筛查/管理/筹资/协同/能力"编码，找制度缝隙。
- **Scoping review（1b）**：PRISMA-ScR。数据库建议中英文双检（PubMed、Embase、Web of Science、Cochrane + 中国知网 CNKI、万方、维普 + WHO/中国疾控 灰色文献）。检索式与纳排见 `02_文献与政策检索策略.md`。产出：证据类型分布图、地域/人群覆盖图、**gap 热力图**。
- **系统综述 + meta（1c，条件）**：仅在窄问题成立时启动，**PROSPERO 预注册**，双人独立筛选 + 偏倚风险评估（RoB2/ROBINS-I/QUADAS-2 视研究类型）。

### 5.2 Phase 2 · 现状实证调查（混合方法，团队分工优势最大化）

- **2a 监测数据回顾性分析**（疾控行政成员牵头，数据入口优势）：结核病管理信息系统、学校聚集性疫情报告、入学体检与密接筛查台账。指标：学生结核发病率/报告率、聚集性疫情频次与规模、密接筛查覆盖率与检出率、诊断延迟、休复学执行率、TPT 开展与完成率。
- **2b 横断面调查**：
  - *机构层面*：学校/校医院/基层医疗机构的**结核病防控管理能力问卷**（对照 WHO 六模块 + 工作规范条目）。
  - *学生层面*：结核病**知信行（KAP）问卷**（可基于现有量表本土化，做信效度检验）。
  - 抽样：分层（学段 × 城乡 × 学校类型），估算样本量并说明。
- **2c 定性研究**：对校医、疾控专干、卫生/教育行政、学生代表做半结构访谈或焦点组；主题分析（thematic analysis），聚焦"管理部门专业能力欠佳"的具体表现与成因。
- **整合**：混合方法采用**解释性序贯或聚合设计**，定量描"是什么"，定性解"为什么"。

### 5.3 Phase 3 · 卫生经济学评价（本研究的"压舱石"）

| 评价类型 | 回答 | 结局单位 | 在本研究中的用途 |
|----------|------|----------|------------------|
| **疾病经济负担 COI** | 学校结核病"花多少钱" | 货币 | 打底，量化问题严重性（直接医疗+直接非医疗+间接[休学/家长误工]+无形成本） |
| **成本-效果 CEA** | 每多发现/避免 1 例花多少 | 每例发现、每例避免传播、每避免 1 起聚集性疫情 | 比较筛查策略 |
| **成本-效用 CUA** | 每 QALY/DALY 花多少 | QALY / DALY | 跨病种可比，便于与其他公卫项目 PK 预算 |
| **成本-效益 CBA** | 净收益/投资回报 | 货币（含 ROI） | 政策倡导、财政沟通最有力 |
| **预算影响分析 BIA** | 纳入基本公卫后**财政多花/省多少** | 货币/年 | ⭐ 决策者最关心，直接支撑改革建议 |

- **建模**：结核病**有传染性**，静态决策树会**低估**预防干预的价值（漏掉阻断二代传播的收益）→ 关键策略建议用**动态传播模型**或至少 Markov 队列模型 + 传播修正。
- **视角与规范**：明确评价视角（卫生体系视角 vs 社会视角，建议双视角）、贴现率、时间跨度；报告遵循 **CHEERS 2022**；参数尽量用 Phase 1–2 的**本地数据**，并做**单因素 + 概率敏感性分析（PSA）**。
- **参考**：中国药物经济学评价指南、WHO-CHOICE 阈值思路（人均 GDP 倍数仅作参考，非硬阈值）。

### 5.4 Phase 4 · 差距分析与改革共识

- **差距分析**：按第 2 节框架（六模块 × 三级预防 × care cascade）做结构化 gap 矩阵，每条 gap 标注"证据来源 + 严重度 + 可干预性"。
- **Delphi 共识**：2–3 轮专家函询（临床 + 预防 + 疾控 + 卫生经济 + 教育行政），把 gap 转化为**排序后的改革建议**，输出可落地路径（谁做、钱从哪来、如何协同、能力如何补）。

## 6. 研究契约：Research Question Card（摘要，全文见 01 号文件）

- **假设（H）**：将学校结核病主动预防（入学筛查 + LTBI 筛查/TPT + 健康教育）制度化并纳入基本公共卫生服务筹资，相较现行"被动发现为主"模式，在可接受成本下能显著降低学生结核发病与聚集性疫情，且具成本-效果优势。
- **现有证据**：待 Phase 1 综述填充（当前为占位，禁止在正式产出中当作已证）。
- **缺失证据**：本地化的筛查检出率、TPT 完成率、单位成本、聚集性疫情的经济损失、纳入基本公卫的预算影响——由 Phase 2–3 补齐。
- **支持标准**：CEA 结果落在可接受阈值内 + BIA 显示财政可承受 + 现状调查证实缺口客观存在。
- **证伪标准**：若主动预防成本-效果比显著劣于被动发现，或聚集性疫情主要归因于非学校可控因素，则假设不成立、改革方向需调整。
- **最小下一步**：完成 Phase 0 研究契约 + 启动 Phase 1 政策梳理与 scoping review 预检索。

## 7. 里程碑 · 分工 · 风险 · 合规

### 7.1 里程碑与团队分工（对应"三位一体"）

| 阶段 | 主要交付物 | 临床（呼吸科） | 预防医学 | 疾控/卫生行政 |
|------|-----------|----------------|----------|----------------|
| 0 | 研究契约 + 方案注册 | 临床问题界定 | 方法学主笔 | 数据可及性、伦理 |
| 1 | Scoping review + 政策分析报告 | 诊疗环节解读 | 综述执行 | 政策文件与灰色文献获取 |
| 2 | 现状调查报告 | 病例/诊断质量把关 | 问卷/抽样/统计 | 监测数据、现场组织协调 |
| 3 | 卫生经济学评价报告 | 临床路径/成本项 | 效果参数 | 财政/管理成本、决策沟通 |
| 4 | 改革建议 + Delphi 共识 | 临床可行性 | 证据整合 | 政策落地路径 |
| 5 | 系列论文 + 政策简报 | 共同作者 | 主笔 | 政策转化 |

### 7.2 主要风险与对策

- **数据可及性风险** → Phase 0 就与数据主管部门签数据使用协议；无法获取则退回到公开监测年报 + 抽样调查。
- **meta 分析做不成的风险** → 预案是系统综述 + 结构化叙述合成，不影响主线。
- **经济学参数缺失风险** → 本地数据优先，缺口用文献 + 敏感性分析覆盖不确定性。
- **多部门协同风险** → 用 Delphi 与联合署名机制绑定利益相关方。

### 7.3 伦理与数据合规

- 涉及学生（含未成年人）问卷/访谈 → **伦理审查（IRB）+ 监护人知情同意**；数据**去标识化**，区分匿名/保密/去标识概念。
- 遵守个人信息保护相关法规；监测数据二次利用需授权。
- **AI 使用披露**：本设计与后续产出如使用 AI 辅助，按目标期刊要求做 AI 使用声明。
