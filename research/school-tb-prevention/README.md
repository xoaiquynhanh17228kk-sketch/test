## 研究范围

**单一地区深做**（v1.1 敲定）：聚焦一个数据可稳定获取的市/区做深度现状调查 + 本地化经济学评价。Scoping review 仍保持全国/国际证据图谱；单点结论须声明可迁移性边界。

## 一分钟结论

- **顺序**：综述在前（首选 scoping review 做"现状"）→ 现状实证调查 → 卫生经济学评价 → 差距分析与改革共识。
- **meta 分析不是起点**，而是综述过程中"发现可合并窄问题"时才启动的条件模块。
- **区别于纯临床**的抓手：学校主动预防与基本公共卫生服务之间的**制度缝隙** + **本地化卫生经济学证据（成本-效果 + 预算影响）**。
