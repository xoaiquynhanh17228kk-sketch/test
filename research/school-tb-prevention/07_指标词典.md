# 附件 07 · 指标词典（Indicator Dictionary · 重庆）

采纳外部 grok 建议的指标体系并做临床/统计校正。**铁律**：凡率类指标统一写清 **分子 · 分母 · 时间窗 · 数据来源 · 责任部门**；能从信息系统导出的不靠回忆问卷；口径全部对齐《中国学校结核病防控指南（2020）》《重庆市学校结核病防控工作规范（2024）》《全国结核病防治规划（2024—2030）》《国家基本公共卫生服务规范（第三版）》——**不自造率**。

> 本词典是 Phase 2 现状调查（`05`）与 Phase 3 经济学（`06`）的共同度量层。分层维度见 F 类"公平"。

## D. 潜伏感染与预防性治疗（TPT）

> **临床校正（临床组把关）**：感染检测方法（TST / TBST-EC 重组结核杆菌融合蛋白 / IGRA）需**分层报告**并固定各自 cutoff（如 TST 强阳 ≥15mm 或有水疱、硬结两年净增 ≥10mm；低龄/免疫抑制者判读不同）。**TPT 方案记法以现行《中国结核病预防性治疗指南/技术规范》为准核对**——原始建议中"3H2P2"疑为 **3HP（异烟肼+利福喷丁每周1次×3月）** 的笔误，团队须逐一核准可用方案（如 3HP、4R、6–9H 等）及**青少年/低龄初中生（部分 <15 岁）剂量**。TPT 前为排除活动性结核对感染阳性者拍胸片，涉及**未成年人放射暴露**，须在伦理与知情同意中说明（见 `00` §7.3）。

| 编号 | 指标 | 分子 / 分母 | 口径 | 数据来源 |
|------|------|-------------|------|----------|
| D1 | 密接潜伏感染检出率 | 感染检测阳性且排除活动性结核 / 完成感染检测的密接 | 检测方法分层报告 | 筛查一览表 |
| D2 | 预防性治疗动员率 | 接受知情同意谈话的符合条件者 / 符合条件者 | 条件：排除活动性后感染检测阳性或指南规定的高危 | 定点医院、疾控 |
| D3 | 预防性治疗接受率 | 开始服药人数 / 符合条件人数 | 对应规划"密接中潜伏感染者预防性治疗率"，2025≥60%、2030≥80% | 门诊登记 |
| D4 | 预防性治疗完成率 | 按方案完成疗程 / 开始服药 | 方案以现行规范核定 | 服药记录 |
| D5 | 在校督导到位率 | 有督促记录的在服学生 / 在校接受 TPT 学生 | 重庆2024明确校医/班主任职责 | 学校 |
| D6 | 拒绝治疗者复查率 | 3、6、12月末完成胸片的拒绝者 / 拒绝者 | 三次都完成才算全程 | 定点医院 |
| D7 | TPT 不良反应中断率 | 因肝损等停药 / 开始服药 | 临床组判定；监测频次与停药规则写入临床方案 | 病历 |

## E. 患者治疗、休复学、基本公卫衔接

| 编号 | 指标 | 分子 / 分母 | 口径 | 数据来源 |
|------|------|-------------|------|----------|
| E1 | 诊断延误 | 症状→首次就诊天数；就诊→确诊天数 | 中位数+P75，按学段与寄宿分层 | 病历、流调 |
| E2 | 休学证明闭环率 | 收到休学证明第三联的病例 / 应休学病例 | 一式三份：学生、定点医院、学校 | 学校、医院 |
| E3 | 复学合规率 | 持复学证明复学 / 复学病例 | 菌阳及重症菌阴须完成全疗程；其他菌阴按规范 2 次涂阴+1 次培阴等 | 复学证明、病历 |
| E4 | 耐多药复学合规率 | 经耐药定点证明+疾控备案后复学 / 复学耐药学生 | **单独报，勿与普通复学混**（分母通常极小，仅描述性） | 耐药定点、疾控 |
| E5 | 基本公卫应管纳入率 | 基层建档并完成首次随访的学生患者 / 应纳入基本公卫的学生患者 | **关键灰区**：住校生按学校所在地还是户籍/居住地纳入，现场写清实际规则 | 基本公卫系统、结防系统 |
| E6 | 72小时入户及时率 | 72h内完成首次访视的学生患者 / 应访视学生患者 | 国家基本公卫规范；住校生实际改电话/找家长要如实记 | 基层记录 |
| E7 | 学生患者规范管理率 | 规范管理学生患者 / 应管理学生患者 | 与国家≥90%口径对齐，但**只算学生** | 基层、疾控 |
| E8 | 成功治疗率 | 治愈+完成治疗 / 纳入队列学生患者 | 与规划≥90%对齐 | 结防系统 |
| E9 | 复学后在校督导率 | 有校医/班主任督导记录 / 复学后仍需服药者 | 菌阴提前复学者是重点 | 学校、医院 |
| E10 | 基本公卫与学校双管率 | 同时有基层随访+学校督导记录的在管学生 / 在管学生患者 | **本课题原创指标**，量"两头都管还是两头都不管" | 三链匹配后 |

## F. 结果与公平

| 编号 | 指标 | 说明 |
|------|------|------|
| F1 | 学校续发 | 指示病例后同一学期同一学校流行病学关联的续发病例数；另报是否达 3 例关联或 10 例事件阈值。**注意机构低报偏倚**（见 `00` §7.2） |
| F2 | 学生肺结核登记率 | 按学段/寄宿/区县报告，以在校学生作分母 |
| F3 | 休学人日 | 从开休学证明到复学的日历日，供经济学间接成本用 |
| F4 | 核心知识知晓率 | 按2024规范附件2的8条核心知识，答对6条及以上为知晓；**阈值需在开题预注册，避免事后调阈值** |
| F5 | 歧视态度得分 | 是否愿意同班/同宿舍、是否主张公开病情，单独成量表 |
| F6 | 公平分层 | 所有率按 寄宿/走读、城乡、学段、本地/跨区域、贫困生（如可得）分层——**平均率会淹没最该改革的人群** |

## G. 经济指标（对接 `06`）

| 编号 | 指标 | 说明 |
|------|------|------|
| G1 | 每名新生完成规定筛查的例均成本 | 检测费+组织费+校医/疾控工时 |
| G2 | 每发现1例学生活动性结核的成本 | 分入学筛查/因症就诊/密接筛查三条路径 |
| G3 | 每完成1例 TPT 的成本 | 含药品、监测、督导、不良反应 |
| G4 | 一起学校散发疫情处置成本 | 流调+筛查+消杀+健康教育+误学 |
| G5 | ICER | **S1对S0、S2对S1**；单位为 元/QALY 与 元/避免1例续发 |
| G6 | 区县年预算影响 | 基本公卫和疾控专项各需增加多少万元（服务 S2 的 BIA） |
| G7 | 基本公卫例均补助缺口 | 现有肺结核管理补助 − 实际服务成本；再估 密接/TPT 纳入后的补助需求 |

## 统计与效能注记（诚实交代）

- E4、D6、F1 等在单城市 3 年可能是**个位数**，只做描述性、不做推断性分层比较。
- 回顾性病例存在**漏报/职业错分**，需捕获-再捕获或名册交叉核对估漏报（见 `05`）。
- 凡"及时率/达标率"优先从系统时间戳导出，不靠回忆。
