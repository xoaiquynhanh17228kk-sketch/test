# 附件 03 · 卫生经济学评价方案（Phase 3 操作手册）

服务于 RQ2。原则：**先算疾病经济负担（COI）打底 → 再做成本-效果 / 成本-效用 + 预算影响分析（BIA）**，报告遵循 **CHEERS 2022**，参数优先用 Phase 1–2 的**本地数据**。

---

## 1. 评价类型与用途

| 类型 | 何时做 | 结局单位 | 面向对象 |
|------|--------|----------|----------|
| 疾病经济负担 COI | 最先，量化问题 | 货币 | 立论、严重性 |
| 成本-效果 CEA | 比较筛查策略 | 每例发现 / 每例避免传播 / 每避免 1 起聚集性疫情 | 技术选择 |
| 成本-效用 CUA | 需跨病种可比时 | QALY / DALY | 与其他公卫项目争预算 |
| 成本-效益 CBA | 政策倡导 | 净收益 / ROI | 财政沟通 |
| 预算影响 BIA | 改革建议阶段 | 元/年 | 决策者（最关心） |

## 2. 关键方法学决策（须在方案中锁定）

- **评价视角**：建议**卫生体系视角 + 社会视角**双报告（社会视角纳入休学、家长误工等间接成本）。
- **比较方案**：现行"被动发现为主" vs 若干"主动预防组合"（入学筛查强度、密接筛查、LTBI 筛查 + TPT、健康教育不同组合）。
- **时间跨度与贴现**：跨度需覆盖 TPT 的长期保护与传播阻断收益；贴现率按本国指南（成本与健康结果同率贴现）。
- **模型类型**：结核**有传染性**，静态模型低估预防价值 →
  - 首选**动态传播模型**（捕捉阻断二代传播的群体收益）；
  - 至少用 **Markov 队列模型**（暴露→感染→发病→治疗→治愈/复发状态），并对传播外部性做修正说明。
- **成本项**：直接医疗（诊断、筛查试剂 IGRA/TST、胸片、治疗、TPT 药品与随访）、直接非医疗（交通）、间接（休学、家长误工）、管理成本（疾控/校医人力、组织）。
- **效果参数**：发病率、筛查覆盖率与检出率、LTBI 阳性率、TPT 完成率与保护效力、聚集性疫情概率与规模——来自 Phase 2 实证 + Phase 1 文献。

## 3. 不确定性分析（必做）

- **单因素敏感性分析**（龙卷风图）——识别驱动结论的关键参数。
- **概率敏感性分析（PSA）**——蒙特卡洛，输出成本-效果可接受曲线（CEAC）。
- **情景分析**——不同发病水平、不同筛查策略强度、不同 TPT 依从率。

## 4. 阈值与解读

- 参考人均 GDP 倍数思路（WHO-CHOICE）作为**沟通参照**，非硬性判定线；结论以 CEAC + BIA 的财政可承受性联合表述。
- 避免"绝对最优"措辞，用"在给定阈值与敏感性分析下，X 策略更可能物有所值"。

## 5. 与基本公共卫生服务的衔接（改革立论）

- 用 BIA 估算：若把学校主动预防关键环节纳入基本公共卫生服务（或专项），**每年新增/节省财政多少**、覆盖多少学生、预计减少多少发病与聚集性疫情。
- 这是 Phase 4 改革建议的核心量化证据。

## 6. 报告与复现

- 遵循 **CHEERS 2022** 逐条报告；公开模型结构、参数表与来源、敏感性分析设定，确保可复现。
