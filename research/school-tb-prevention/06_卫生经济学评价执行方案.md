# 附件 06 · 卫生经济学评价执行方案（Phase 3 · 单一地区）

把 `03` 号方案展开为可执行结构。参数以目标地区 Phase 2 数据为主、文献为辅；单点参数须在敏感性分析中覆盖不确定性，并声明可迁移性边界。报告遵循 **CHEERS 2022**。

---

## 1. 决策问题与比较方案（comparators）

**目标人群**：目标地区一个学生入学队列（按学段建亚组）。

| 方案 | 内容 |
|------|------|
| S0（对照） | 现行"被动发现为主"：症状就诊 + 常规入学体检 + 被动密接筛查 |
| S1 | 强化入学筛查（结构化症状筛查 → 异常者 TST/IGRA → 胸片） |
| S2 | 强化密接筛查 + 规范处置 |
| S3 | LTBI 筛查 + 预防性治疗（TPT）覆盖阳性学生 |
| S4 | 组合策略（S1+S3±健康教育强化） |

## 2. 模型结构（两层 + 传播修正）

- **短期决策树**：从"筛查策略 → 检出/漏诊 → 确诊/治疗"，比较每策略的**早期发现**与筛查成本。产出 CEA 结局：每多发现 1 例、每避免 1 起聚集性疫情的成本。
- **长期 Markov 队列**：状态 = {未感染、潜伏感染 LTBI、活动性结核、治疗中、治愈、结核相关死亡}；循环周期 1 年，时间跨度覆盖 TPT 的长期保护（建议 ≥ 学制年限，或终生 + 贴现）。产出 CUA 结局：QALY / DALY。
- **传播外部性修正**：结核有传染性，纯队列模型会**低估**预防收益。首选**动态传播模型**（含二代传播）；若资源受限，至少对"阻断的二代病例"做情景加算，并在局限性中说明。

## 3. 视角、贴现、阈值

- **视角**：卫生体系视角 + 社会视角**双报告**（社会视角纳入休学、家长误工等间接成本）。
- **贴现**：成本与健康结果同率贴现，按本国指南取值（如常用 5%，敏感性分析取 0%/3%/8%）。
- **阈值**：以人均 GDP 倍数（WHO-CHOICE 思路）作**沟通参照**而非硬判定；结论用**成本-效果可接受曲线（CEAC）+ 预算可承受性**联合表述。

## 5. 分析计划

- **基线分析**：各策略 vs S0 的增量成本、增量效果、ICER；列成本-效果前沿。
- **单因素敏感性分析**：龙卷风图，识别驱动结论的关键参数（预期为 TPT 完成率、发病率、筛查成本、传播修正强度）。
- **概率敏感性分析（PSA）**：蒙特卡洛（≥ 5000 次）→ CEAC。
- **情景分析**：高/低发病水平；TPT 完成率高/低；是否计入传播外部性；卫生 vs 社会视角。
- **预算影响分析（BIA，服务改革建议）**：以目标地区学生规模，估算 S3/S4 纳入常规筹资后**年度净财政影响**、覆盖人数、预计减少发病与聚集性疫情——Phase 4 改革建议的核心量化证据。

## 6. 单一地区的外推处理

- 结果表述为"该地区证据支持"，非全国普适；关键参数标注来源与年份。
- 提供参数可迁移性讨论（哪些参数地区间差异大：发病率、成本、依从率），便于他地借用模型。
- 二期可扩多地区参数做外推性检验。
