## 0. 一句话结论

**CIH 造模成功**（自发活动与探索行为显著下降，效应量极大）；**但 NOR 判别指数在对照组呈显著反向（偏好旧物体），说明该行为学范式在当前评分方式下尚未成立，识别记忆数据不可用于任何结论。**

因此本次预实验的定位应为：**造模有效性验证 + 行为学方法学预试**，而非"BHD 改善认知"的效应学证据。

## 3. 核心问题诊断

### 3.1 ★ NOR 未成立：对照组显著偏好旧物体

这是本次预实验最关键的发现。健康对照必须表现出新物体偏好（DI > 0）才能证明范式有效；实际 Sham 组 DI = −0.363（p=0.017），方向完全相反。在对照组失效的前提下，CIH 组与 BHD 组的 DI 无论数值如何都不可解释。

**候选原因（按可能性排序）：**

1. **探究时间的操作性定义错误（最可能）。** 当前使用软件"物体-中心 区域时间"，即动物中心点落在物体周围圆形区域内的停留时间。该量包含贴靠物体休息、绕行、路过等非探究行为。NOR 的标准读出是**鼻端定向探究时间**：鼻尖距物体 ≤2 cm 且头部朝向物体；爬骑（climbing）与啃咬（chewing）不计入。两者在小鼠上可低相关甚至反相关——一只在旧物体旁长时间静止的动物会得到很高的"旧物体区域时间"。

2. **训练-测试间隔过短且不符方案。** 实际间隔约 4.7 h（同日 09:20 → 14:04），V4.5 方案规定 24 h。短间隔下测的是短时记忆，且下午测试叠加昼夜节律与前次操作应激。

3. **物体/位置未平衡。** 训练期 3 只动物侧偏好 |指数| > 0.23（对照1 +0.304、对照2 +0.231、CD3-1 +0.356），提示两个位置不等价。若新物体固定放在其中一侧且未在动物间平衡（counterbalance），位置偏好会系统性掩盖或反转新物体偏好。原始记录中未见平衡方案，需核对。

4. **气味残留。** 每只动物之间是否用 75% 乙醇擦拭箱体与物体、是否更换物体本体，原始数据无法判断，需核对操作记录。

### 3.2 两只动物未达 NOR 通行纳入阈值

标准：训练期与测试期探究总时间均需 ≥20 s。

| ID | T1 (s) | T2 (s) | 判定 |
|---|---|---|---|
| CIH-2 | 3.07 | 2.87 | **✗ 排除**（几乎完全不探究物体） |
| CD3-1 | 56.16 | 17.80 | **✗ 排除**（T2 未达阈值） |
| 其余 7 只 | ≥34.67 | ≥23.46 | ✓ |

按此标准有效 n 为 Sham 3 / CIH 2 / BHD 2。**该纳入排除标准必须在正式实验中预注册（揭盲前锁定），不得事后调整。**

### 3.3 测试顺序与分组共线

测试期时间戳：对照 14:04–14:19 → CIH+BHD 14:12–14:19 → CIH 14:25–14:40。组别与时钟时间、测试顺序完全混杂，无法区分"CIH 效应"与"越晚测越疲劳/环境气味累积"。训练期同样按组集中（对照 → CIH → CD3）。

### 3.4 活动度下降对 NOR 的混杂

CIH 组测试期探究总时间 18.6 s vs Sham 44.4 s。当动物整体探索意愿显著下降时，DI 的估计方差急剧增大（CIH 组 DI 的 SD 达 0.483，是 Sham 组的 6 倍）。这本身就要求 NOR 结论必须与自发活动指标联合解释，或改用对活动度不敏感的记忆范式。

### 3.5 数据标注

动物 ID `CHI-BIO-CD3-x` 中 `CHI` 应为 `CIH`；`BIO`、`CD3` 的含义需在实验记录中定义（推测 CD3 = 中剂量 7.01 g/kg）。建议订正原始导出文件并建立 ID 命名规范，以保证数据可追溯。

## 4. 可以写进开题报告的结论

**可以写：**

1. 课题组已完成 CIH 造模预实验（n=3/组），**造模有效**：CIH 组自发活动显著降低（总路程 −35.5%，p=0.004，Hedges g=3.87；不动时间 +78%，p=0.015，g=−2.65）。
2. CIH+BHD 组自发活动与不动时间均向 Sham 水平回归（vs CIH，p=0.061–0.070，g=1.60–1.69），**方向一致、效应量大，但 n=3 功效不足，仅作趋势描述**。
3. 课题组已通过预实验识别出 NOR 范式的四项方法学问题并制定改进方案（见第 5 节）——这是正式实验方案 V5 的直接依据。

**不可以写：**

- ✗ "BHD 改善 CIH 小鼠的识别记忆"——对照组 DI 反向，该结论无数据支持。
- ✗ 任何直接引用当前 DI 数值的组间比较。
- ✗ 把 CIH-2、CD3-1 纳入后计算的任何统计量。

**风险提示**：若在开题汇报中用当前 DI 讲"BHD 改善认知"，评委只需追问"对照组的判别指数是多少"即会当场暴露。反之，把它讲成"预实验发现范式问题并已给出改进方案"，直接对应评分标准 B 组"研究思路严密、科研思维严谨"与 D 组"调研扎实、有初步研究结果"，是加分项。

## 5. 正式实验的行为学方案修订建议（拟并入 V5）

| # | 问题 | 修订 |
|---|---|---|
| R1 | 探究时间用区域停留时间 | 改为**鼻端定向探究时间**：鼻尖距物体 ≤2 cm 且朝向物体；爬骑、啃咬、背向倚靠不计。软件自动评分须与人工评分做一致性验证（≥20 只，双人盲法，ICC ≥0.80），否则改人工盲法计时 |
| R2 | 间隔 4.7 h，不符方案 | 恢复 **24 h** 间隔（V4.5 原定）；如需同时评估短时与长时记忆，设 1 h 与 24 h 两个独立测试并分别报告 |
| R3 | 物体/位置未平衡 | 新物体的**位置与身份在动物间完全平衡**（A/B 物体各半、左/右各半，四种组合均衡分配）；训练期侧偏好 \|指数\| >0.20 的动物预先记录为敏感性分析变量 |
| R4 | 测试顺序与分组共线 | 测试顺序**按组交错并随机化**（区组随机），记录每只动物的测试时钟时间作为协变量备查 |
| R5 | 纳入排除未预注册 | 预注册：T1 与 T2 探究总时间均 ≥20 s；不达标者排除并在结果中报告排除数与组别分布 |
| R6 | 活动度混杂 | NOR 结论必须与旷场自发活动联合解释；在统计模型中把总路程作为协变量做敏感性分析；考虑加入**对活动度不敏感**的记忆范式（如 Morris 水迷宫已在方案内，可作为主判据） |
| R7 | 气味/清洁 SOP 未见记录 | 明确 SOP：每只动物之间 75% 乙醇擦拭箱体与物体并晾干；物体准备复本轮换 |
| R8 | 样本量 | 预实验 n=3 仅用于造模验证与流程调试。正式实验按 V4.5 队列 A n=8/组执行；可用本次活动度效应量（g≈2.6–3.9）反推，n=8 对该量级效应功效充足，但对 NOR DI 需另行估算 |
| R9 | 数据标注 | 订正 `CHI` → `CIH`；建立 ID 命名规范与数据字典 |

**建议：MWM（Morris 水迷宫）在正式实验中作为海马依赖性记忆的主判据，NOR 作为次要判据**——MWM 对活动度差异的敏感性可通过游泳速度协变量控制，且本课题 CIH 组存在明显活动度下降，NOR 的解释风险更高。
