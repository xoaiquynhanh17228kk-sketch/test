## 1. 开题报告正文（V4.1 基线）↔ 主实验方案 V4.5 的四项冲突

### 1.1 EMCS 几何改变的方向 —— **裁定：采用 V4.5 双侧口径**

| | 内容 |
|---|---|
| 开题报告正文（V4.1） | 假说写死单侧："接触面积增加、紧密接触比例升高和接触距离缩短" |
| 主实验方案 V4.5 | 方向不预设，双侧检验。理由：文献证据分歧——提示扩张的有 Sassano 2025（肿瘤细胞）、Yan 2026（鱼肝、持续低氧）、Jiang 2026（脊髓 SCI）；提示破坏的有 Moulin 2022（小鼠心 + 人心房，IH 21 d，MAM 破坏、HIF-1 依赖）、Zhai 2026（小鼠脑 DA 神经元，CIH，Mfn2-Plin5 系链破坏且恢复系链具保护性）。注意后两项恰是**间歇低氧 + 哺乳动物在体**，与本模型最接近 |
| **统一口径** | **双侧，方向由数据判定**。假说表述为"CIH 导致 EMCS 几何**病理性重塑**（方向不预设）；BHD 通过**使 EMCS 几何趋向 Sham 水平**发挥保护"。L1 底线证据"BHD 逆转 CIH-EMCS 病理重塑"本身即方向无关，双侧设计不削弱论文主线 |
| 落实 | 开题报告正文三（一）研究假说需改写；PPT 第 10 页专设"扩张 vs 破坏"证据分歧页；决策树保留情形 H |

### 1.2 队列 C 设计 —— **裁定：采用 V4.5 周期内急性时点**

| | 内容 |
|---|---|
| 开题报告正文（V4.1） | Sham、CIH；W2/W4 各 n=4，共 16 只；产出"W2、W4 时序动态证据" |
| 主实验方案 V4.5 §3.3 | Sham、CIH 各 n=8，共 16 只；**单次低氧-复氧循环的复氧相结束即刻**灌注取材（周期内急性时点）；慢性时点 W6 由队列 A 提供，二者构成"急性 vs 慢性"对照。理由：原 W2/W4/W6 三时点均属慢性、结果高度冗余且各仅 n=4 功效不足 |

### 1.3 距离-结局关系的形状 —— **裁定：采用 V4.5 形状不预设**

| | 内容 |
|---|---|
| 开题报告正文（V4.1） | 隐含单调："若 30 nm-EML 组本身已明显减轻损伤，而加用 BHD 后不再出现额外保护……" |
| 主实验方案 V4.5 §8.3 | **形状不预设**。一手证据：Dematteis 2024（EML 工具原始论文）报告 ER-OMM 距离与钙转移/氧化代谢呈**钟形关系、峰值约 20 nm**；Csordas 2010 独立报告 linker 长度对 ER-线粒体钙信号有 biphasic effect 并提示存在 optimal gap width。**铁死亡易感性是否同样呈钟形，尚无任何研究在距离梯度上验证过——这正是本实验要回答的问题** |
| **统一口径** | 两步检验：①omnibus ANOVA/Kruskal-Wallis 检验"距离是否影响结局"；②同一模型内**并列拟合线性对比与二次对比**并同时报告。二次项显著 → 钟形；仅线性项显著 → 单调 |
| BHD 依赖性预测 | 保持"G9 ≈ G6（几何被钳制后药物失去作用空间）"；**但不得再表述为"EMCS 已被推远 = 已被保护"**，因钟形框架下 30 nm 是偏离最优点的一侧，功能后果须由数据判定 |
| 落实 | 开题报告正文四（五）、PPT 第 25 页 |

## 2. 开题报告正文缺失、但必须补入的条目

以下四条 V4.5 已有或预实验新增，开题报告正文未体现。它们恰是"研究基础扎实、方法学准备充分"的最好证据。

### 2.1 IP3R1 一抗更换（V4.5 §6.3）

原 ab5804 官方反应种属仅列人与大鼠、**未列小鼠**，验证应用为 IHC-P/ICC-IF、**不含 WB**，与本课题 C57BL/6J 小鼠不匹配。已更换为 **Proteintech 19962-1-AP**（反应种属含人/小鼠/大鼠，验证应用含 IHC、WB、FC、IP；IP3R1 观察分子量 290–300 kDa）。兔 + 鼠异种搭配不变，PLA 试剂盒仍为 DUO92101。采购须为**未偶联版本**。

### 2.2 PLA 的 mouse-on-mouse 背景对照（V4.5 §6.3）

VDAC1 一抗 ab14734 为**小鼠**单抗、实验组织为**小鼠**脑，anti-Mouse MINUS 探针会结合内源性小鼠 IgG 造成高背景。必须：①使用 M.O.M. 阻断试剂；②设"省略一抗、仅加 PLA 探针"对照与"仅一支一抗"单抗体对照，与实验样本同批处理。另：ab14734 官方标注为 Anti-VDAC1/Porin + **VDAC3**，故指标须严格表述为"IP3R1 与 VDAC1/VDAC3 的邻近信号"。

### 2.3 EML 引文自查更正（V4.5 §8.1）

V4.2 及以前误记为「Pavenius et al., Nat Commun 2024 / Filadi-Pizzo 实验室」，作者、期刊、实验室三项均误。正确出处为 **Dematteis G, Tapella L, Casali C, …, Genazzani AA, Lim D. (2024). Commun Biol. 7(1):1294**。且 Addgene 可商购者仅 **15/20/30 nm 三档**，5/10 nm 在原文中系 Hajnóczky 实验室赠予、不在 Addgene。

> 这一条主动写进"前期工作基础"是加分而非减分：它证明课题组对关键工具做了一手核实。

### 2.4 ★ 预实验行为学结果（2026-07-27，本次新增）

详见 `docs/预实验行为学结果分析.md`。

**可写入开题材料的结论**：

- CIH 造模**有效**：测试期总路程 Sham 1031 ± 49 vs CIH 665 ± 95 cm（p=0.004，Hedges g=3.87）；不动时间 17.3 ± 3.8% vs 30.8 ± 4.3%（p=0.015，g=−2.65）。
- CIH+BHD 组两项指标均向 Sham 回归（vs CIH，p=0.061–0.070，g=1.60–1.69），**方向一致、效应量大，但 n=3 功效不足，仅作趋势描述**。
- 已通过预实验识别 NOR 范式四项方法学问题并制定 R1–R9 改进方案。

**禁止写入**：

- ✗ "BHD 改善 CIH 小鼠识别记忆"。**对照组判别指数 DI = −0.363（p=0.017），显著偏好旧物体，NOR 范式在当前评分方式下未成立**，DI 数据不可用于任何组间结论。
- ✗ 纳入 CIH-2（探究总时间 2.87 s）与 CD3-1（17.80 s）后计算的任何统计量——二者未达 ≥20 s 通行阈值。

## 3. 由预实验衍生、需并入 V5 的方案修订

| # | 条目 | 修订要点 |
|---|---|---|
| R1 | 探究时间定义 | 区域停留时间 → **鼻端定向探究时间**（鼻尖 ≤2 cm 且朝向物体；爬骑、啃咬、背向倚靠不计）；软件评分须与人工盲法评分做一致性验证（ICC ≥0.80） |
| R2 | 训练-测试间隔 | 恢复 **24 h**（预实验实为 4.7 h） |
| R3 | 物体与位置平衡 | 新物体身份与位置在动物间**完全平衡**（A/B × 左/右四组合均衡分配） |
| R4 | 测试顺序 | **按组交错、区组随机化**（预实验中组别与测试时钟时间完全共线）；记录测试时间作协变量 |
| R5 | 纳入排除 | 预注册：T1 与 T2 探究总时间均 ≥20 s；报告排除数与组别分布 |
| R6 | 活动度混杂 | **MWM 作为海马依赖性记忆主判据，NOR 降为次要判据**；NOR 结论须与自发活动联合解释，总路程作协变量做敏感性分析 |
| R7 | 清洁 SOP | 每只动物间 75% 乙醇擦拭箱体与物体并晾干，物体准备复本轮换 |
| R8 | 样本量 | 正式实验按 V4.5 队列 A n=8/组；NOR DI 的样本量需在范式修正后重新估算（当前 DI 数据不可用于估算） |
| R9 | 数据标注 | 订正 `CHI` → `CIH`；定义 `BIO`、`CD3` 含义；建立 ID 命名规范与数据字典 |
